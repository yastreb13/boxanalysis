# boxanalysis
Скорость удара в боксе
Система компьютерного зрения для детекции боксёрских перчаток и измерения скорости ударов в реальном времени. Проект объединяет трекинг скелета, кастомную нейросеть для экипировки и фильтрацию кинематических параметров.
Трекинг суставов: отслеживание ключевых точек тела (плечи, локти, запястья, бёдра) через MediaPipe Pose.
Фильтрация шумов: сглаживание углов и расчёт угловой скорости в суставах рук с помощью двумерного фильтра Калмана.
Аналитика удара:
Автоматическая фиксация фазы удара (пороги старта и завершения движения).
Расчёт мгновенной скорости кулака.
Фиксация и отображение пиковой скорости для каждой руки отдельно.
Видеопайплайн: прямой захват с камеры через DirectShow и параллельное аппаратное сохранение результата в файл (output_boxing.mp4) через потоки FFmpeg.
Математика: 
Рука моделируется как двухзвенный механизм. Линейная скорость кулака вычисляется через матрицу Якоби, связывающую длины звеньев (L1 — плечо, L2 — предплечье), текущие углы (th1 — плечо, th2 — локоть) и их угловые скорости (w1, w2)
1. Элементы матрицы Якоби (J):

J11 = -L1 * sin(th1) - L2 * sin(th1 + th2)

J12 = -L2 * sin(th1 + th2)

J21 =  L1 * cos(th1) + L2 * cos(th1 + th2)

J22 =  L2 * cos(th1 + th2)

2. Компоненты вектора скорости кулака (Vx, Vy):

Vx = J11 * w1 + J12 * w2

Vy = J21 * w1 + J22 * w2

3. Итоговая линейная скорость:

Speed = sqrt(Vx^2 + Vy^2)

Для фильтра Калмана:
Вектор состояния фильтра содержит 4 параметра: [th1, th2, w1, w2] (два угла и две их скорости). На каждом кадре фильтр делает два шага:

1. (Prediction):
Фильтр рассчитывает, какими должны быть углы прямо сейчас, исходя из физики (сохранения скорости с прошлого кадра):

th_predicted = th_prev + w_prev * dt

2. (Update):
Фильтр берет новые, «шумные» углы от MediaPipe и смешивает их со своим предсказанием. На выходе он выдает очищенные значения.
Для фильтрации шумовых колебаний скорости и исключения ложных срабатываний (программного дребезга) применяется гистерезис с двумя независимыми порогами:
Гистерезис наибольшей скорости удара:

PUNCH_START — порог инициации удара.

PUNCH_END — порог завершения удара.

Логика работы:

Переход в состояние удара происходит при превышении PUNCH_START.

Выход при падении ниже PUNCH_END.
